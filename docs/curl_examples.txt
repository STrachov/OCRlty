- Find the value printed to the RIGHT of that label on the same line.
- "Same line" means the value token’s bounding box vertically overlaps the label token’s bounding box.
- If multiple numbers are on the right, choose the closest one to the label (smallest horizontal gap).

- Output MUST be copied EXACTLY from the OCR tokens (character-for-character).
